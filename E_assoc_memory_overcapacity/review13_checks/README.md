# 审查 13 的独立检查

结论及解释见根目录 `PROOF_REVIEW13.md`。本目录没有 Y3 新 MR 训练数据，没有使用其计划流生成样本或查询，没有项目代码导入和 LLM API。

- `independent_audit_v2.py`：物理响应积分、确定性协方差族的一阶系数、球面单项式联合矩、X1 原始记录 RMSE、逐查询配对方差及功效、记录熵与随机初始化扫描、既有文件哈希核对。
- `kernel_budget.py`：确定性非 MR 测试张量的同尺寸 GEMM、比较和平方和计时。不是预注册实验或新 MR pilot。
- `complete_seed_and_report_stats.py`：补齐无完整记录熵的旧初始化域，归纳功效数字与系数源码依赖。
- `final_validate.py`：核对90行预测、所有冻结项、既有文件未变，并生成本次产物哈希。

运行必须使用报告中的 systemd、3G、零 swap、指定 Python 和≤2线程前缀，且逐个执行。输出排他创建，原样重跑会拒绝覆盖。若需复查，应另新建输出位置和脚本名。

`independent_audit.py` 是保留的失败首版：只因同一项目的挂载路径别名导致断言失败，未执行数值核验。v2 仅改用目录身份比较。失败和成功的日志都保留。

功效输出为 **X1 旧数据方差加查询数修正的规划外推**；d512 的方差从 d256 外推，候选预测作为假定真值。不能把这些规划数字称为已观测 d512 科学结果或严格功效保证。各表的位移、SE、区间半宽单位是百分点（pp）；系数 B 则是 recall 比例乘 d。
